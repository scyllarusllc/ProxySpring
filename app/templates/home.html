Install the extension

Install ProxySpring from the Chrome Web Store with one click. To build it yourself, run npm run build in the repository, open chrome://extensions, turn on Developer mode and load dist/extension. Then paste your proxies on the Connect page and press Import, and press Start proxy or wait for the countdown. Local addresses always connect directly. The extension only rewrites Chrome’s proxy settings after you turn the proxy on.
